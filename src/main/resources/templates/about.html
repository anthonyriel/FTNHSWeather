System Architecture & Guidelines

Learn how the automated Learning Mode Decision System evaluates weather conditions for Fermin Tayabas National High School.

Project Purpose

The FTNHS Weather Hub is an institutional decision-support tool engineered to automate and streamline learning modality transitions (In-Person, Modular, or Suspended). By eliminating manual delays during inclement weather, it ensures student and faculty safety while maintaining academic continuity.

Weather Data Source

The system synchronizes in real-time with the Open-Meteo API, polling high-resolution meteorological data covering precipitation rate, ambient temperature, wind speed, relative humidity, and cloud cover specifically mapped to the school's geographical coordinates.

Decision Algorithm & Threshold Standards

Based on standard meteorological rainfall thresholds and DepEd advisory guidelines.

Rainfall Rate (mm/hr) Evaluated Learning Mode Operational Action & Description
< 7.5 mm/hr IN-PERSON Normal weather conditions. Standard face-to-face classes proceed as scheduled.
7.5 to 15.0 mm/hr MODULAR Moderate rainfall warning (Yellow Advisory equivalent). Transition to modular learning recommended.
> 15.0 mm/hr SUSPENDED Heavy rainfall / severe weather risk (Orange/Red Advisory equivalent). Classes automatically suspended for safety.
Institutional Disclaimer

This system serves as an automated decision-support tool for Fermin Tayabas National High School administrators, teachers, parents, and students. While automated algorithms execute 15-minute evaluations, school administration retains full authority to enforce manual overrides during local emergencies or official DepEd orders.
